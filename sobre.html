FICÇÃO INTERATIVA

Um arquivo para investigar

O Núcleo Lázaro, seus departamentos, relatórios e incidentes são elementos ficcionais criados para uma experiência narrativa de mistério e terror investigativo.

COMO JOGAR

  1. Leia os três dossiês principais.
  2. Observe códigos, horários, frases repetidas e contradições.
  3. Abra o Terminal e experimente comandos citados nos documentos.
  4. Use o memorando para identificar as três referências corretas no Protocolo 0.
  5. Depois de desbloquear o fragmento, abra o Registro de Origem.

PRIVACIDADE E SEGURANÇA

Este pacote é um site estático. O terminal e os formulários funcionam localmente no navegador e não enviam informações. Não representa uma agência real, não acessa sistemas governamentais e não solicita dados pessoais.

PUBLICAÇÃO

Você pode publicar os arquivos como site estático usando GitHub Pages ou outro serviço de hospedagem. Consulte o arquivo LEIA-ME incluído no pacote. O site ainda não foi publicado automaticamente.
